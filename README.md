# VIVA-X – AI Viva Examiner 🎓

**Prepare smarter. Perform confidently.**

VIVA-X is an AI-powered virtual viva platform designed to help students prepare for oral examinations through interactive questioning, adaptive difficulty, and personalized performance feedback.

🌐 **Live Demo:** https://viva-x-fawn.vercel.app/

## 📌 Problem Statement

Students often struggle to prepare for viva examinations because they lack opportunities to practice answering questions, evaluate their conceptual understanding, and identify weak topics.

VIVA-X aims to provide an interactive practice environment that helps students assess their preparation and improve their confidence.

## ✨ Key Features

- **AI-Generated Questions:** Generate viva questions based on selected subjects and topics.
- **Adaptive Difficulty:** Adjust the difficulty of questions based on students' responses.
- **Intelligent Follow-up Questions:** Explore conceptual understanding through additional questions.
- **Performance Analysis:** Evaluate responses and provide feedback on knowledge, confidence, and communication.
- **Weak Topic Detection:** Identify topics that need further revision.
- **Viva Readiness Report:** Present a summary of performance and areas for improvement.
- **Session History:** Review previous practice sessions and track progress.

## 🛠️ Technology Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Backend:** Next.js server-side routes
- **Database and Authentication:** Firebase (where configured)
- **AI Integration:** Google Gemini AI
- **Deployment:** Vercel

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- Git
- Firebase project and Google Gemini API access, if required by your configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/pralhaddeshpande117-source/VIVA-X.git
   ```

2. Navigate to the project directory:

   ```bash
   cd VIVA-X
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root and configure the environment variables required by the application.

   **Security note:** Never commit real API keys, passwords, service-account credentials, or other secrets to GitHub.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔐 Environment Configuration

Configure the Firebase and Gemini variables required by the application using the names expected by the source code.

Keep private credentials in local environment files or secure deployment environment settings. Do not publish real secret values in this README.
